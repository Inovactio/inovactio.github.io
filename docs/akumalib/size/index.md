# The size system

A body's size is the library's `SIZE` attribute: its box, its eyes, its model, its blows and its abilities all follow it. One page per part of the system.

| Page | What it covers |
|---|---|
| [Reading a size](reading-size.md) | `SizeScale`: reading `SIZE`, the curve that bends what forms and effects add, the limit |
| [What `SIZE` does to a body](body.md) | box, eyes, camera, model, shadow, hearing, particles and sounds |
| [Bodies taller than a man](big-bodies.md) | step height, walk, jump, fall, health, regeneration, pushes, sinking, menus, room on arrival |
| [A race's size and the creator's slider](race-size.md) | `AkumaSize.setBodySize`, `AkumaRaces.setSize`, the slider, the server switches, bodies under 1 |
| [Forms that make their user bigger](forms.md) | `FormSizes`: declaring a form's size, its modes, migrating an addon's form |
| [Melee](melee.md) | reach, a form's own reach, strength and swing of a big body |
| [Abilities that follow the size](abilities.md) | `AkumaSize`: the factor families, what grows by itself, an addon's scale of the factors |
| [Hits and sizes written by hand](written-sizes.md) | `AkumaSize.hurt`, the size-aware blocks, spawns that inherit a size, grabs of several bodies |
| [The ability context](ability-context.md) | searches, helpers and rays grown while an ability runs, `/akumalib searchsize` |
| [Settings and tests](settings-and-tests.md) | every `[sizeSystem]` setting, who follows, exempt abilities, census, size guard, area test |
| [Size defects register](../utilities/size-defects.md) | every size defect found so far, its cause and the shared fix to reuse |

For a bonus held on any attribute, not only the size, see [Attribute bonuses](../utilities/attribute-bonuses.md).
