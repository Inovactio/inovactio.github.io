# Suna Suna no Mi

**Logia** · 3 awakened abilities

These abilities unlock once the fruit is **awakened**: see [Awakening](../index.md#getting-started).

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Sabaku no Okoku { #sabaku-no-okoku }

![](../abilities/sabaku-no-okoku.png){ .ability-icon } *Active · Zone*

Dries out the ground for a huge area around the user, turning it into the user's desert.

Once fully spread quicksand fills the field three blocks deep and only the user can stand on it

Everything inside dries up and loses the water it carries.

| Stat | Value |
|---|---|
| Cooldown | 60 s |
| Charge | 1–6 s |
| Range | 110 blocks (area) |
| Moisture Drain (per pulse) | 1–4.5 |

## Sabaku no Sousou { #sabaku-no-sousou }

![](../abilities/sabaku-no-sousou.png){ .ability-icon } *Active*

Rips the quicksand out of the desert and pushes it forward, burying everything it hits

Anything the sand reaches gets dragged under and held there.

Damage goes up with the sand swallowed, and the sand goes back into the field

| Stat | Value |
|---|---|
| Cooldown | 35 s |
| Charge | 2 s |
| Range | 40 blocks (line) |
| Damage | 25–150 |

## Kawaki { #kawaki }

![](../abilities/kawaki.png){ .ability-icon } *Passive*

Standing on sand makes the user faster, stronger and heal quicker.

Their own quicksand works best and stops fall damage

Gives nothing on any other ground.

| Stat | Value |
|---|---|
| Movement Speed (%) | +12.5–25 |
| Bonus Punch Damage | +2.5–5 |
| Natural Regeneration (x) | 1.5–2 |
