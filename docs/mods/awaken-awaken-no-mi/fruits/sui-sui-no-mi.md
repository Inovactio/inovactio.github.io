# Sui Sui no Mi

**Paramecia** · 3 awakened abilities

These abilities unlock once the fruit is **awakened**: see [Awakening](../index.md#getting-started).

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Waterpool Domain { #waterpool-domain }

*Active · Zone*

Turns the ground into liquid: the user and their allies swim through it, while enemies sink and drown in it.

Inside it the user counts as swimming for Nekomimi Punch and the Nyan Nyan Suplexes.

| Stat | Value |
|---|---|
| Cooldown | 120 s |
| Charge | 3–12 s |
| Zone Radius (blocks) | 128 |
| Effect Pulse (s) | 0.5 |

## Undertow { #undertow }

*Active*

Grabs the enemy in front and drags them down into the ground, swimming off with them while they drown.

Using it again, or holding on too long, throws them back out of the ground wherever the user is.

| Stat | Value |
|---|---|
| Cooldown | 30 s |
| Hold | 4 s |
| Range | 4 blocks (line) |
| Damage | 40 |

## Breach { #breach }

*Active*

Sends the user's presence swimming through the ground toward the targeted enemy, then breaches beneath them in a violent burst.

Enemies close to the target are caught in the eruption too.

| Stat | Value |
|---|---|
| Cooldown | 25 s |
| Range | 40 blocks (line) |
| Damage | 70 |
