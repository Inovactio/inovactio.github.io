## Waterpool Domain { #waterpool-domain }

![](../abilities/waterpool-domain.png){ .ability-icon } *Active · Zone*

Applies ![](../effect-icons/ground-drown.png){ .effect-mini .pixelated }[Ground Drown](../effects.md#effect-ground-drown)

Turns the ground into liquid, the user and their allies can swim in it while enemies sink and drown.

Inside it the user counts as swimming for Nekomimi Punch and the Nyan Nyan Suplexes.

| Stat | Value |
|---|---|
| Cooldown | 120 s |
| Charge | 3–12 s |
| Zone Radius (blocks) | 128 |
| Effect Pulse (s) | 0.5 |

## Undertow { #undertow }

![](../abilities/undertow.png){ .ability-icon } *Active*

Applies ![](../effect-icons/undertow-held.png){ .effect-mini .pixelated }[Undertow Held](../effects.md#effect-undertow-held)

Grabs the enemy in front and drags them down into the ground, swimming off with them while they drown.

Using it again, or holding on too long, throws them back out of the ground wherever the user is.

| Stat | Value |
|---|---|
| Cooldown | 30 s |
| Hold | 4 s |
| Range | 4 blocks (line) |
| Damage | 40 |

## Breach { #breach }

![](../abilities/breach.png){ .ability-icon } *Active*

Sends a fin swimming through the ground toward the targeted enemy, then it bursts out from under them.

Enemies close to the target get hit too.

| Stat | Value |
|---|---|
| Cooldown | 25 s |
| Range | 40 blocks (line) |
| Damage | 70 |
