# Wara Wara no Mi

**Paramecia** · 3 awakened abilities

These abilities unlock once the fruit is **awakened**: see [Awakening](../index.md#getting-started).

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Harvest of Fate { #harvest-of-fate }

*Active*

Rips the straw doll out of every nearby enemy at once.

Guarding enemies keep their doll and the user still can't carry more than ten

| Stat | Value |
|---|---|
| Cooldown | 45 s |
| Charge | 3 s |
| Range | 16 blocks (area) |

## Nail of Fate { #nail-of-fate }

*Active*

Drives a nail into the straw doll in the main hand, hitting its owner wherever they are.

The doll is used up and goes back to its owner

| Stat | Value |
|---|---|
| Cooldown | 20 s |
| Damage | 60 |

## Shared Fate { #shared-fate }

*Passive*

Damage the user takes is also dealt to the owners of every straw doll they carry.

The user still takes their own damage normally
