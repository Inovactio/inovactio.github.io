# Kobu Kobu No Mi

**Paramecia** · 3 awakened abilities

These abilities unlock once the fruit is **awakened**: see [Awakening](../index.md#getting-started).

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## One Man Army { #one-man-army }

*Active*

The user pushes past their limits for a short time, becoming a one-man army.

| Stat | Value |
|---|---|
| Charge | 3 s |
| Hold | 60 s |
| Cooldown | 60–180 s |
| Unconscious Afterwards (s) | 0–15 |

**Stats while active**

| Stat | Value |
|---|---|
| Attack Speed | +2 |
| Step Height | +1 |
| Armor | +10 |
| Armor Toughness | +5 |
| Knockback Resistance | +6 |
| Toughness | +5 |
| Jump Height | +15 |
| Punch Damage | +20 |
| Speed | x3.5 |
| Fall Resistance | +30 |

## Battlefield Resonance { #battlefield-resonance }

*Active · Zone*

Creates a zone that gives the user and every ally inside it Speed I and Resistance I.

When an ally hits an enemy inside the zone, every ally inside gets Battlefield Resonance for 5 seconds: +50% damage, speed and jump, +25% attack speed.

| Stat | Value |
|---|---|
| Cooldown | 120 s |
| Charge | 3–12 s |
| Zone Radius (blocks) | 128 |
| Inside the Zone | Speed, Resistance |

## Never Surrender { #never-surrender }

*Passive*

When the user or an ally nearby is about to fall, the user's voice rallies them back to their feet.

They gain a burst of absorption, Strength II and Resistance II, and shake off Negative and Unconscious.

| Stat | Value |
|---|---|
| Range (blocks) | 24 |
| Rallies Below (% health) | 30 |
| Absorption Granted | 60 |
| Boost Duration (s) | 10 |
| Once Per Person Every (s) | 90 |
