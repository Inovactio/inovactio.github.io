# Doa Doa no Mi

| | |
|---|---|
| **Type** | Paramecia |
| **Abilities** | 3: 2 active, 1 passive |
| **Zones** | [Hide and Seek](#hide-and-seek) |

These abilities unlock once the fruit is **awakened**: see [Awakening](../index.md#getting-started).

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Hide and Seek { #hide-and-seek }

![](../abilities/hide-and-seek.png){ .ability-icon } *Active · Zone*

Drags everyone in the zone into a sealed pocket dimension until the user lets them out or time runs out.

| Stat | Value |
|---|---|
| Cooldown | 240 s |
| Charge | 2 s |
| Zone Radius (blocks) | 20 |

## Living Gate { #living-gate }

![](../abilities/living-gate.png){ .ability-icon } *Active*

The user turns into a door, blocking physical attacks and swallowing incoming projectiles

When the door closes it fires every projectile back at 1.5x speed where the user is looking.

| Stat | Value |
|---|---|
| Cooldown | 30 s |
| Hold | 10 s |

## Backdoor { #backdoor }

![](../abilities/backdoor.png){ .ability-icon } *Passive*

Door Door aimed at an enemy opens the door behind them instead of through a wall.

The user's next blow on them within a few seconds opens a door in their body, dealing damage that ignores armour.

| Stat | Value |
|---|---|
| Range (blocks) | 32 |
| Armour-Ignoring Strike Damage | 40 |
| Strike Window (s) | 3 |
