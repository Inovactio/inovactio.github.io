# Yuki Yuki no Mi

| | |
|---|---|
| **Type** | Logia |
| **Abilities** | 3: 2 active, 1 passive |
| **Zones** | [Yukiro](#yukiro) |

These abilities unlock once the fruit is **awakened**: see [Awakening](../index.md#getting-started).

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Yukiro { #yukiro }

![](../abilities/yukiro.png){ .ability-icon } *Active · Zone*

Spreads snow around the user and raises a wall of hard snow at the edge that only the user can walk through

Letting go early makes a smaller ring, and the cold inside keeps building until it turns to ice.

Hard snow burns easily so a torch is a way out

| Stat | Value |
|---|---|
| Cooldown | 90 s |
| Charge | 2–6 s |
| Zone Radius (blocks) | 36 |
| Effect Pulse (s) | 2 |
| Wall Height (blocks) | 9 |
| Frostbite Stacks (per pulse) | 2 |
| Cooldown If Released Early (s) | 20 |

## Gokkan { #gokkan }

![](../abilities/gokkan.png){ .ability-icon } *Active*

Drops the temperature so low that everything nearby freezes solid instantly.

Skips the usual frost buildup and freezes enemies right away

| Stat | Value |
|---|---|
| Cooldown | 35 s |
| Charge | 3 s |
| Range | 24 blocks (area) |
| Damage | 95 |
| Frozen For (s) | 7 |

## Kanpa { #kanpa }

![](../abilities/kanpa.png){ .ability-icon } *Passive*

Frost on enemies near the user stops fading and turns to ice much sooner.

The frost starts fading again once they leave the cold

| Stat | Value |
|---|---|
| Range (blocks) | 24 |
| Freezes At (stacks) | 5 |
| Frost Held For (s) | 7 |
| Frozen For (s) | 5 |
