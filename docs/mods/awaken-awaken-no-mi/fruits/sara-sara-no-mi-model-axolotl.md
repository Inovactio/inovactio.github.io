## Cellular Overload { #cellular-overload }

![](../abilities/cellular-overload.png){ .ability-icon } *Active*

Applies ![](../effect-icons/cellular-overload.png){ .effect-mini .pixelated }[Cellular Overload](../effects.md#effect-cellular-overload)

Pushes the axolotl's cells past their limits, removing every bad effect that can be removed, and for a short time most of the health the user loses grows back in a few seconds.

When it ends the user gets really hungry.

| Stat | Value |
|---|---|
| Cooldown | 60 s |
| Hold | 10 s |
| Damage Regrown (%) | 75 |
| Regrown Over (s) | 3 |
| Natural Regeneration (x) | 3 |

## Toxic Bloom { #toxic-bloom }

![](../abilities/toxic-bloom.png){ .ability-icon } *Active*

Releases all the poison stored in Toxic Reserve at once, hurting and poisoning the enemies around.

The more health was stored, the harder it hits.

| Stat | Value |
|---|---|
| Cooldown | 15–45 s |
| Damage | 15–150 |
| Range | 12 blocks (area) |
| Healing Released As Damage (%) | 150 |

## Toxic Reserve { #toxic-reserve }

![](../abilities/toxic-reserve.png){ .ability-icon } *Passive*

While in an awakened form all the health the axolotl regenerates is stored as poison in its body, Toxic Bloom can release it.

The poison slowly goes away once the user stops fighting.

| Stat | Value |
|---|---|
| Healing Stored (max) | 100 |
| Seeps Away After No Fighting For (s) | 10 |
