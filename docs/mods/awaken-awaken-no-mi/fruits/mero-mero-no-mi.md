# Mero Mero no Mi

| | |
|---|---|
| **Type** | Paramecia |
| **Abilities** | 3: 2 active, 1 passive |
| **Effects applied** | ![](../effect-icons/enthralled.png){ .effect-mini .pixelated }[Enthralled](../effects.md#effect-enthralled) |

These abilities unlock once the fruit is **awakened**: see [Awakening](../index.md#getting-started).

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Love's Punishment { #loves-punishment }

![](../abilities/loves-punishment.png){ .ability-icon } *Passive · Aura*

Enemies that get too close fall in love and slowly turn to stone.

| Stat | Value |
|---|---|
| Range | 14 blocks (area) |

## Enthralling Gaze { #enthralling-gaze }

![](../abilities/enthralling-gaze.png){ .ability-icon } *Active*

Applies ![](../effect-icons/enthralled.png){ .effect-mini .pixelated }[Enthralled](../effects.md#effect-enthralled)

Every enemy nearby that is looking at the user gets charmed and can't hurt her for a while.

The charmed can still move, use their abilities and attack anyone else.

| Stat | Value |
|---|---|
| Cooldown | 45 s |
| Range | 32 blocks (area) |

## Heart Rebound { #heart-rebound }

![](../abilities/heart-rebound.png){ .ability-icon } *Active*

Throws a big heart that goes through everything in its way and comes back to the user, hitting each enemy it passes on the way there and back.

On its way back it drags the enemies it strikes toward the user.

| Stat | Value |
|---|---|
| Cooldown | 20 s |
| Range | 30 blocks (line) |
| Damage | 70 |
