# Jiki Jiki no Mi

**Paramecia** · 3 awakened abilities

These abilities unlock once the fruit is **awakened**: see [Awakening](../index.md#getting-started).

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Assign World { #assign-world }

*Active · Zone*

Magnetizes the ground into scrap that drags down enemies wearing metal and pulls their weapons away.

Scrap Tempest uses the scrap from the field instead of the user's inventory

| Stat | Value |
|---|---|
| Cooldown | 120 s |
| Charge | 2–6 s |
| Range | 60 blocks (area) |

## Scrap Tempest { #scrap-tempest }

*Active*

Rips the scrap out of the ground and slams it down on the aimed spot, crushing everything nearby.

More scrap makes a heavier hit, outside the field it uses the user's own metal instead

| Stat | Value |
|---|---|
| Cooldown | 15–45 s |
| Charge | 2 s |
| Damage | 24–88 |
| Range | 14 blocks (area) |

## Ferrous Dominion { #ferrous-dominion }

*Passive*

Standing on the user's magnetic field gives them armor, stronger hits and knockback resistance.

The field also pulls loose metal toward the user, even weapons it pulled from enemies
