# Kage Kage no Mi

**Paramecia** · 3 awakened abilities

These abilities unlock once the fruit is **awakened**: see [Awakening](../index.md#getting-started).

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Nightmare Banquet { #nightmare-banquet }

*Active · Zone*

Spreads the user's shadow over a huge area, stealing the shadow of every weaker enemy caught in it

| Stat | Value |
|---|---|
| Cooldown | 120 s |
| Charge | 3–12 s |
| Zone Radius (blocks) | 128 |
| Effect Pulse (s) | 2 |

## Shadow Marionette { #shadow-marionette }

*Active*

Takes control of an enemy with no shadow, beasts fight for the user and people can't hit the user or their allies.

Only works on targets without a shadow and costs stolen shadows.

| Stat | Value |
|---|---|
| Cooldown | 30–180 s |
| Hold on Beasts (s) | 90–180 |
| Hold on People (s) | 15–45 |
| Range (blocks) | 12 |
| Shadows Spent | 10 |

## Sunless Brand { #sunless-brand }

*Passive*

Enemies near the user with no shadow burn even without sunlight or open sky.

Works no matter who took the shadow, it stops once they get far enough away

| Stat | Value |
|---|---|
| Zone Radius (blocks) | 16 |
| Damage | 5 |
