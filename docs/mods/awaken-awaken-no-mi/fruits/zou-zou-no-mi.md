These abilities unlock once the fruit is **awakened**: see [Awakening](../index.md#getting-started).

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Ivory Catastrophe { #ivory-catastrophe }

![](../abilities/ivory-catastrophe.png){ .ability-icon } *Active*

Charges forward spinning with huge tusks, impaling everything in the way.

| Stat | Value |
|---|---|
| Cooldown | 60 s |
| Hold | 8 s |
| Damage | 120 |

## Trunk Geyser { #trunk-geyser }

![](../abilities/trunk-geyser.png){ .ability-icon } *Active*

The elephant raises its trunk and shoots a jet of seawater that pushes back everything in its way and puts out fire.

Devil Fruit users hit by it lose their powers for a moment like if they fell in the sea.

| Stat | Value |
|---|---|
| Damage | 25 |
| Full Jet Damage per Enemy | 150 |
| Devil Fruit Sealed After Soaking (s) | 4 |
| Range | 32 blocks (line) |
| Hold | 3 s |
| Cooldown | 45 s |
