# Netsu Netsu no Mi

**Paramecia** · 3 awakened abilities

These abilities unlock once the fruit is **awakened**: see [Awakening](../index.md#getting-started).

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Netto Jigoku { #netto-jigoku }

![](../abilities/netto-jigoku.png){ .ability-icon } *Active · Zone*

Applies ![](../effect-icons/inferno.png){ .effect-mini .pixelated }[Inferno](../effects.md#effect-inferno)

Creates a burning zone around the user, enemies inside get more burn stacks the longer they stay.

| Stat | Value |
|---|---|
| Cooldown | 120 s |
| Charge | 3–12 s |
| Zone Radius (blocks) | 128 |
| Effect Pulse (s) | 1 |

## Melting Point { #melting-point }

![](../abilities/melting-point.png){ .ability-icon } *Active*

Applies ![](../effect-icons/molten-armor.png){ .effect-mini .pixelated }[Molten Armor](../effects.md#effect-molten-armor)

Releases a wave of heat that turns the metal worn by nearby enemies red-hot, burning them every second for a while.

The more metal they carry, the worse it burns; taking it off or wearing diamond stops it.

| Stat | Value |
|---|---|
| Cooldown | 60 s |
| Range | 24 blocks (area) |
| Damage | 0–16 |

## Scorching Fist { #scorching-fist }

![](../abilities/scorching-fist.png){ .ability-icon } *Active · Punch*

Applies ![](../effect-icons/inferno.png){ .effect-mini .pixelated }[Inferno](../effects.md#effect-inferno)

Gathers the heat of the whole body into the next punch, which explodes on impact and burns everyone around the target.

The target is left with several [Inferno](../effects.md#effect-inferno) stacks.

| Stat | Value |
|---|---|
| Damage | 40–90 |
