# Magu Magu no Mi

**Logia** · 3 awakened abilities

These abilities unlock once the fruit is **awakened**: see [Awakening](../index.md#getting-started).

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Meigo no Jidai { #meigo-no-jidai }

*Active*

Melts the ground in a huge wave around the user, leaving burning magma and basalt behind.

| Stat | Value |
|---|---|
| Damage | 60 |
| Cooldown | 240 s |
| Charge | 10 s |
| Range | 120 blocks (area) |

## Kagutsuchi { #kagutsuchi }

*Active · Punch*

Coats the user's fists in overheated magma, every punch lands like an eruption.

Each hit burns a quarter of the Netsuryo gauge so the first punch hits the hardest.

| Stat | Value |
|---|---|
| Attack Damage | 35–110 |
| Heat Burned Per Hit | 25 |

## Netsuryo { #netsuryo }

*Passive*

The user stores heat while standing on magma, and twice as fast while standing in lava

Stored heat turns into armor, the fuller the gauge the tougher the user gets.

Heat slowly drains away from lava and Kagutsuchi burns it with every punch.

| Stat | Value |
|---|---|
| Armor | +2–8 |
| Toughness | +1.5–6 |
| Movement Speed (%) | +5–20 |
