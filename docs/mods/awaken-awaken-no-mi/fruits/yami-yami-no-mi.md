# Yami Yami no Mi

| | |
|---|---|
| **Type** | Logia |
| **Abilities** | 3: 2 active, 1 passive |
| **Zones** | [Kyomu](#kyomu) |

These abilities unlock once the fruit is **awakened**: see [Awakening](../index.md#getting-started).

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Kyomu { #kyomu }

![](../abilities/kyomu.png){ .ability-icon } *Active · Zone*

Opens a dark void where no Devil Fruit works and the darkness hurts anyone inside.

Devil Fruits stay silenced for a moment after leaving the void

| Stat | Value |
|---|---|
| Cooldown | 180 s |
| Charge | 3–10 s |
| Zone Radius (blocks) | 40 |
| Effect Pulse (s) | 1 |
| Damage | 3 |

## Singularity { #singularity }

![](../abilities/singularity.png){ .ability-icon } *Active*

Collapses every block the user has swallowed onto a single point, dragging everything nearby into it.

The more darkness was hoarded, the heavier the collapse - and it spends all of it.

| Stat | Value |
|---|---|
| Collapse Damage | 60–180 |
| Collapse Radius (blocks) | 12 |
| Blocks For A Full Collapse | 22,000 |
| Charge | 3 s |
| Cooldown | 90 s |

## Gluttony { #gluttony }

![](../abilities/gluttony.png){ .ability-icon } *Passive*

Everything the user has swallowed adds weight to their hits.

The more they have stored, the harder they hit and the less damage they take

Using up the stock takes the bonus away with it.

| Stat | Value |
|---|---|
| Bonus Punch Damage | +4–8 |
| Attack Damage | +3–6 |
| Toughness | +4–8 |
