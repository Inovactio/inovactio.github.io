# Zushi Zushi no Mi

**Paramecia** · 3 awakened abilities

These abilities unlock once the fruit is **awakened**: see [Awakening](../index.md#getting-started).

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Ukiyo { #ukiyo }

*Active · Zone*

Turns off gravity in the zone, lifting every enemy off the ground and leaving them floating helpless

When the zone ends everyone falls back down, the higher they floated the harder they land.

| Stat | Value |
|---|---|
| Cooldown | 150 s |
| Charge | 3–10 s |
| Zone Radius (blocks) | 48 |
| Effect Pulse (s) | 1 |
| Suspension Height (blocks) | 22 |
| Damage | 30–140 |

## Deadweight { #deadweight }

*Active*

The user fixes one enemy in their sight and piles the weight of the sky onto it alone.

The pressure builds with every moment, driving the target into the ground and ignoring armor.

Looking away lets the weight go.

| Stat | Value |
|---|---|
| Crush Damage per Pulse | 16–48 |
| Full Channel Damage | 160 |
| Seize Range (blocks) | 32 |
| Hold | 4 s |
| Cooldown | 45 s |

## Zenith { #zenith }

*Passive*

The higher the user is off the ground, the harder they hit and the faster they fly

The user never takes fall damage.

Gives nothing while standing on solid ground

| Stat | Value |
|---|---|
| Bonus Punch Damage | +3.5–7 |
| Flight Speed (%) | +60–120 |
