# Awa Awa no Mi

**Paramecia** · 3 awakened abilities

These abilities unlock once the fruit is **awakened**: see [Awakening](../index.md#getting-started).

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## World Wash { #world-wash }

*Active · Zone*

Creates a big soap zone around the user that washes everyone inside, leaving them weak and unable to fight

| Stat | Value |
|---|---|
| Cooldown | 120 s |
| Charge | 3–12 s |
| Zone Radius (blocks) | 128 |
| Effect Pulse (s) | 2.5 |

## Bubble Cage { #bubble-cage }

*Active*

Fires a giant soap bubble that traps the first enemy hit so they can't move or attack.

The bubble bursts at the end or when used again, dealing damage and washing away their buffs.

| Stat | Value |
|---|---|
| Cooldown | 45 s |
| Charge | 1 s |
| Hold | 10 s |
| Damage | 120 |

## Squeaky Clean { #squeaky-clean }

*Passive*

The user's hits deal a lot more damage to washed enemies.

Each hit keeps the enemy washed for a few more seconds
