## Rebirth Blaze { #rebirth-blaze }

![](../abilities/rebirth-blaze.png){ .ability-icon } *Active*

Every bit of health it takes back erupts as a nova that burns enemies around it and mends its allies.

| Range | 16 blocks (area) |
| Hold | 3 s |
| Cooldown | 120 s |
