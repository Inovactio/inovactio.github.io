## Ao no Rakka { #ao-no-rakka }

![](../abilities/ao-no-rakka.png){ .ability-icon } *Active*

The user dives wrapped in blue flames hitting all enemies in the way, healing from the first three hits.

| Stat | Value |
|---|---|
| Cooldown | 45 s |
| Hold | 5 s |
| Damage | 60 |
| Heal | 20 |

## Rebirth Blaze { #rebirth-blaze }

![](../abilities/rebirth-blaze.png){ .ability-icon } *Active*

The phoenix bursts into blue flames and floats in the air, nothing can hurt it until it comes back at full health.

All the health it gets back explodes out as a nova that burns enemies around and heals allies.

| Stat | Value |
|---|---|
| Nova Damage (health restored) | 40–150 |
| Allies' Missing Health Mended (%) | 50 |
| Range | 16 blocks (area) |
| Hold | 3 s |
| Cooldown | 120 s |
