# Pika Pika no Mi

| | |
|---|---|
| **Type** | Logia |
| **Abilities** | 3: 2 active, 1 passive |
| **Zones** | [Lightfall Domain](#lightfall-domain) |

These abilities unlock once the fruit is **awakened**: see [Awakening](../index.md#getting-started).

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Lightfall Domain { #lightfall-domain }

![](../abilities/lightfall-domain.png){ .ability-icon } *Active · Zone*

Creates a dome where it is always bright daylight, even at night or deep underground.

Every enemy inside glows and can be seen through walls

The dome does not hurt anyone.

| Stat | Value |
|---|---|
| Cooldown | 45 s |
| Charge | 3–9 s |
| Zone Radius (blocks) | 128 |
| Effect Pulse (s) | 2 |

## Kousoku { #kousoku }

![](../abilities/kousoku.png){ .ability-icon } *Active*

Fires a beam of light that hits instantly, striking everything along the line of sight

The beam bounces off surfaces to reach down corridors and around corners.

Deals massive damage in daylight but barely anything in the dark

| Stat | Value |
|---|---|
| Cooldown | 23 s |
| Charge | 2 s |
| Damage | 44–110 |

## Sun's Blessing { #hi-no-megumi }

![](../abilities/hi-no-megumi.png){ .ability-icon } *Passive*

The brighter the light around the user, the faster, stronger and quicker to heal they get.

Darkness gives no bonus but no penalty either

| Stat | Value |
|---|---|
| Movement Speed (%) | +12.5–25 |
| Bonus Punch Damage | +2.5–5 |
| Natural Regeneration (x) | 1.5–2 |
