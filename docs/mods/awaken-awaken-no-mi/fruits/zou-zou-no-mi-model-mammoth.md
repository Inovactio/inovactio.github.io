# Zou Zou no Mi, Model: Mammoth

| | |
|---|---|
| **Type** | Ancient Zoan |
| **Abilities** | 3: 2 active, 1 passive |

These abilities unlock once the fruit is **awakened**: see [Awakening](../index.md#getting-started).

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Drought Calamity { #drought-calamity }

![](../abilities/drought-calamity.png){ .ability-icon } *Active*

Stomps the ground so hard all the water in the area dries up, leaving a wasteland and rotting enemies.

| Stat | Value |
|---|---|
| Cooldown | 60 s |
| Charge | 3 s |
| Range | 24 blocks (area) |
| Damage | 70 |

## Drought Siphon { #drought-siphon }

![](../abilities/drought-siphon.png){ .ability-icon } *Active*

The mammoth raises its trunk and sucks the water out of every enemy around it, healing from up to three of them.

Enemies that are wet from water or rain lose twice as much and are left dried out and slowed.

| Stat | Value |
|---|---|
| Drain per Pulse | 12 |
| Full Channel Drain per Enemy | 96 |
| Drain on Wet Enemies | x2 |
| Range | 18 blocks (area) |
| Hold | 8 s |
| Cooldown | 45 s |

## Ancient Hide { #ancient-hide }

![](../abilities/ancient-hide.png){ .ability-icon } *Passive*

In an awakened form a single hit can never take more than a small part of the mammoth's health.

Its wool keeps it warm so it can't be frozen or get frostbite.

| Stat | Value |
|---|---|
| Largest Blow Taken (% of max health) | 15 |
