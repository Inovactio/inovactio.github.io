# Moku Moku no Mi

| | |
|---|---|
| **Type** | Logia |
| **Abilities** | 3: 2 active, 1 passive |
| **Zones** | [White Night](#white-night) |

These abilities unlock once the fruit is **awakened**: see [Awakening](../index.md#getting-started).

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## White Night { #white-night }

![](../abilities/white-night.png){ .ability-icon } *Active · Zone*

Fills the sky with white smoke that marks and blinds everyone caught inside

Enemies that stay in the smoke start choking harder the longer they stay.

The mark lasts after the dome and works with White Pull and Smoke Launch

| Stat | Value |
|---|---|
| Cooldown | 45 s |
| Charge | 3–9 s |
| Zone Radius (blocks) | 128 |
| Effect Pulse (s) | 2 |
| Damage | 6–20 |

## White Ash { #white-ash }

![](../abilities/white-ash.png){ .ability-icon } *Active*

Burns off all the smoke on the field at once, hurting every marked enemy.

More smoke on a target means more damage

Enemies with no smoke on them are not hurt.

| Stat | Value |
|---|---|
| Cooldown | 30 s |
| Charge | 3 s |
| Range | 100 blocks (area) |
| Damage | 30–130 |

## White Plague { #white-plague }

![](../abilities/white-plague.png){ .ability-icon } *Passive*

Marked enemies near the user spread the smoke to whoever stands next to them

Smoke spread this way is thin and needs another ability to thicken it.

| Stat | Value |
|---|---|
| Range (blocks) | 48 |
| Contagion Radius (blocks) | 10 |
| Smoke Passed On (s) | 15 |
