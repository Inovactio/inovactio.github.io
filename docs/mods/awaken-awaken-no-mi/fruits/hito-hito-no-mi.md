# Hito Hito no Mi

**Zoan** · 3 awakened abilities

These abilities unlock once the fruit is **awakened**: see [Awakening](../index.md#getting-started).

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Awaken Human Form { #awaken-human-form }

*Active · Transformation*

Transforms the user into an awakened human, which focuses on strength.

**Stats while active**

| Stat | Value |
|---|---|
| Attack Speed | +1.2 |
| Step Height | +1 |
| Armor | +15 |
| Max Health | x1.25 |
| Armor Toughness | +10 |
| Knockback Resistance | +1 |
| Toughness | +3 |
| Jump Height | +8 |
| Punch Damage | +10 |
| Speed | +2.1 |
| Fall Resistance | +10 |

## Insight { #insight }

*Active*

The user studies an enemy for a moment and finds their weak points

Every hit on that enemy deals more damage and goes through half their armor.

| Stat | Value |
|---|---|
| Cooldown | 45 s |
| Charge | 2 s |
| Hold | 20 s |
| Range (blocks) | 32 |
| Damage On Weak Points (%) | +50 |
| Armor Ignored (%) | 50 |

## Adaptive Mind { #adaptive-mind }

*Passive*

Each kind of damage the user takes makes them tougher against that same kind

A kind of damage that stops coming is forgotten after a while.

| Stat | Value |
|---|---|
| Resistance Per Hit (%) | +10 |
| Max Resistance Per Kind (%) | 60 |
