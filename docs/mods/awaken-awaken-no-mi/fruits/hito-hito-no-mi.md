## Insight { #insight }

![](../abilities/insight.png){ .ability-icon } *Active*

The user studies an enemy for a moment and finds their weak points

Every hit on that enemy deals more damage and goes through half their armor.

| Stat | Value |
|---|---|
| Cooldown | 45 s |
| Charge | 2 s |
| Hold | 20 s |
| Range (blocks) | 32 |
| Damage On Weak Points (%) | +50 |
| Armor Ignored (%) | 50 |

## Adaptive Mind { #adaptive-mind }

![](../abilities/adaptive-mind.png){ .ability-icon } *Passive*

Each kind of damage the user takes makes them tougher against that same kind

A kind of damage that stops coming is forgotten after a while.

| Stat | Value |
|---|---|
| Resistance Per Hit (%) | +10 |
| Max Resistance Per Kind (%) | 60 |
