# Ope Ope no Mi

| | |
|---|---|
| **Type** | Paramecia |
| **Abilities** | 4: 3 active, 1 passive |
| **Effects applied** | ![](../effect-icons/anesthesia.png){ .effect-mini .pixelated }[Anesthesia](../effects.md#effect-anesthesia) |

These abilities unlock once the fruit is **awakened**: see [Awakening](../index.md#getting-started).

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## K-Room { #k-room }

![](../abilities/k-room.png){ .ability-icon } *Active*

Applies ![](../effect-icons/anesthesia.png){ .effect-mini .pixelated }[Anesthesia](../effects.md#effect-anesthesia)

**Modes**

- **Arm Mode**: Coats the arm in a tiny Room. When awakened Anesthesia works through this coating.
- **Weapon Mode**: Coats the held weapon in a tiny Room. When awakened Anesthesia works through this coating.

| Stat | Value |
|---|---|
| Charge | 1 s |
| Hold | 60 s |
| Cooldown | 20 s |

## Shock Wille { #shock-wille }

![](../abilities/shock-wille.png){ .ability-icon } *Active*

Sends an electric shock through the K-Room so the next hit deals massive damage through armor

| Stat | Value |
|---|---|
| Damage | 180 |
| Hold | 10 s |
| Cooldown | 60 s |

## Puncture Wille { #puncture-wille }

![](../abilities/puncture-wille.png){ .ability-icon } *Active*

The user plants the coated hand and a huge spike of Room comes out of the ground where they are aiming.

Everything around it is run through, ignoring armor, and thrown into the air.

| Stat | Value |
|---|---|
| Spire Damage | 130 |
| Spire Radius (blocks) | 6 |
| Opening Range (blocks) | 40 |
| Charge | 2 s |
| Cooldown | 60 s |

## Anesthesia { #anesthesia }

![](../abilities/anesthesia.png){ .ability-icon } *Passive*

Applies ![](../effect-icons/anesthesia.png){ .effect-mini .pixelated }[Anesthesia](../effects.md#effect-anesthesia)

While K-Room is active every hit the user lands puts the target under Anesthesia.

The user and their allies ignore the invulnerability frames of anyone under Anesthesia so every hit does full damage.

| Stat | Value |
|---|---|
| Coated Fist Damage | 30 |
| Coated Weapon Damage | 20 |
| Anesthesia Duration (s) | 6 |
| Numbed Attack Speed (%) | -40 |
| Numbed Attack Damage (%) | -25 |
| Numbed Movement Speed (%) | -25 |
