# Nagi Nagi no Mi

**Paramecia** · 3 awakened abilities

These abilities unlock once the fruit is **awakened**: see [Awakening](../index.md#getting-started).

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Total Isolation { #total-isolation }

![](../abilities/total-isolation.png){ .ability-icon } *Active · Punch*

Applies ![](../effect-icons/total-isolation.png){ .effect-mini .pixelated }[Total Isolation](../effects.md#effect-total-isolation)

Traps a target in a soundproof bubble that cuts off all sounds and chat for them.

## Soundless Step { #soundless-step }

![](../abilities/soundless-step.png){ .ability-icon } *Active · Punch*

The user moves without making a single sound: monsters lose track of them and can't find them again.

The first blow breaks the silence and lands with crushing force.

## Dead Air { #dead-air }

![](../abilities/dead-air.png){ .ability-icon } *Passive*

While Silent is active, enemies around the user can't use Observation Haki: no aura can see them and no future sight can dodge them.

| Stat | Value |
|---|---|
| Range | 30 blocks (area) |
