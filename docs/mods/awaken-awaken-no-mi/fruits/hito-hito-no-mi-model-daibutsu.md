## Nyorai Shinshō { #nyorai-shinsho }

![](../abilities/nyorai-shinsho.png){ .ability-icon } *Active*

Applies ![](../effect-icons/buddha-seal.png){ .effect-mini .pixelated }[Buddha Seal](../effects.md#effect-buddha-seal)

Drops a giant Buddha palm from the sky onto the aimed spot, crushing everything under it.

Anything it lands on is pinned to the ground for 40 seconds, unable to walk, swim or jump

| Stat | Value |
|---|---|

| Charge | 1 s |
| Damage | 120 |

## Sanctuary { #sanctuary }

![](../abilities/sanctuary.png){ .ability-icon } *Active*

Every hit aimed at an ally nearby hits the user instead.

The hit stays the same kind so the user's armour still protects them. It breaks after the user took enough damage.

| Stat | Value |
|---|---|
| Cooldown | 90 s |
| Hold | 60 s |
| Shelters Allies Within (blocks) | 24 |
| Breaks After Taking (HP) | 300 |
