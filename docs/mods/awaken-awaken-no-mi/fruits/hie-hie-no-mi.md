# Hie Hie no Mi

**Logia** · 3 awakened abilities

These abilities unlock once the fruit is **awakened**: see [Awakening](../index.md#getting-started).

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Ice Epoch { #ice-epoch }

*Active*

Freezes the ground in a huge wave around the user, turning it into a glacier and trapping enemies in ice

| Stat | Value |
|---|---|
| Cooldown | 240 s |
| Charge | 10 s |
| Range | 120 blocks (area) |

## Hyosai { #hyosai }

*Active*

Shatters every frozen enemy nearby all at once.

Enemies that are not already frozen are not affected

| Stat | Value |
|---|---|
| Cooldown | 30 s |
| Charge | 2 s |
| Range | 24 blocks (area) |
| Attack Damage | 140 |

## Hyoten { #hyoten }

*Passive*

Every frozen or frostbitten enemy nearby makes the user faster, stronger and harder to knock back.

The more frozen enemies around, the bigger the bonus.

Gives nothing when no enemy nearby is frozen.

| Stat | Value |
|---|---|
| Movement Speed (%) | +15–30 |
| Bonus Punch Damage | +3.5–7 |
| Toughness | +3–6 |
