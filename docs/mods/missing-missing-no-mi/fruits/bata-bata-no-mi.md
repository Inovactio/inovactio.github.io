Found in the base mod's **wooden Devil Fruit box**. Eat it and its abilities appear in the ability menu, grouped under the fruit.

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Butter Lump { #bata-lump }

![](../abilities/bata-lump.png){ .ability-icon } *Active*

![Butter Lump](../objects/bata-lump.png){ .form-picture }

The user throws a lump of butter where they look. It hits the first enemy in its way and slows it for a moment

| Stat | Value |
|---|---|
| Damage type | Blunt, Projectile |
| Haki | Special |
| Cooldown | 4 s |
| Range | 54 blocks (line) |
| Damage | 5 |

## Butter Cuffs { #bata-cuffs }

![](../abilities/bata-cuffs.png){ .ability-icon } *Active*

![Butter Cuffs](../objects/bata-cuffs.png){ .form-picture }

Applies ![](../effect-icons/butter-cuffs.png){ .effect-mini }[Butter Cuffs](../effects.md#effect-butter-cuffs), ![](../effect-icons/butter-wrap.png){ .effect-mini }[Butter Wrap](../effects.md#effect-butter-wrap)

The user throws a ball of butter where they look. It wraps the hands of the first enemy it hits, who can't hit or use what it holds

The butter lasts a shorter time on a player. Hits from someone else break it sooner and fire melts it

| Stat | Value |
|---|---|
| Cooldown | 12 s |
| Range | 12 blocks (line) |
| Hold | 8 s |

## Butter Wrap { #bata-wrap }

![](../abilities/bata-wrap.png){ .ability-icon } *Active*

![Butter Wrap](../objects/bata-wrap.png){ .form-picture }

Applies ![](../effect-icons/butter-cuffs.png){ .effect-mini }[Butter Cuffs](../effects.md#effect-butter-cuffs), ![](../effect-icons/butter-wrap.png){ .effect-mini }[Butter Wrap](../effects.md#effect-butter-wrap)

The user throws a ball of butter where they look. It wraps the whole body of the first enemy it hits, who can't move or hit

The butter lasts a shorter time on a player. Hits from someone else break it sooner and fire melts it

| Stat | Value |
|---|---|
| Cooldown | 18 s |
| Range | 12 blocks (line) |
| Hold | 6 s |

## Sticky Sheet { #bata-sheet }

![](../abilities/bata-sheet.png){ .ability-icon } *Active*

The user spreads soft butter on the ground where they look. Everyone who walks in it gets stuck and can't jump, friend and enemy, but not the user

Using it again takes the butter back

| Stat | Value |
|---|---|
| Cooldown | 18 s |
| Hold | 10 s |
| Range | 10 blocks (line) |
| Range | 5 blocks (area) |
| Charge | 0 s |

## Butter Slide { #bata-slide }

![](../abilities/bata-slide.png){ .ability-icon } *Active*

The user slides fast on their own butter and leaves a sticky trail behind. Everyone who follows on it gets stuck

Using it again stops the slide and takes the trail back

| Stat | Value |
|---|---|
| Cooldown | 15 s |
| Hold | 10 s |
| Charge | 0 s |

## Burning Butter { #bata-burning }

![](../abilities/bata-burning.png){ .ability-icon } *Active*

Applies ![](../effect-icons/butter-cuffs.png){ .effect-mini }[Butter Cuffs](../effects.md#effect-butter-cuffs), ![](../effect-icons/butter-wrap.png){ .effect-mini }[Butter Wrap](../effects.md#effect-butter-wrap)

The user heats all their butter at once. Everyone held in the user's butter is burnt, and every enemy standing in it a little less. Then the butter melts away

| Stat | Value |
|---|---|
| Damage type | Indirect |
| Element | Fire |
| Haki | Special |
| Cooldown | 20 s |
| Damage | 12 |
| Damage | 8 |
| Range | 24 blocks (area) |
