Found in the base mod's **iron Devil Fruit box**. Eat it and its abilities appear in the ability menu, grouped under the fruit.

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Fever { #shiku-fever }

![](../abilities/shiku-fever.png){ .ability-icon } *Active*

The user gives a fever to the enemy they look at. The sick one moves slower and hits weaker.

It passes to everyone near the sick one but never back to the user. A strong Haki breaks it and cures the sick around.

| Stat | Value |
|---|---|
| Their speed | -30 % |
| Their blows deal | 70 % |
| Cooldown | 15 s |
| Range | 8 blocks (line) |
| Lasts | 20 s |
| Spreads within | 2.5 blocks |
| Other diseases wait | 6 s |

## Wasting { #shiku-wasting }

![](../abilities/shiku-wasting.png){ .ability-icon } *Active*

The user makes the enemy they look at waste away. The sick one loses life every second and nothing heals it.

It passes to everyone near the sick one but never back to the user. A strong Haki breaks it and cures the sick around.

| Stat | Value |
|---|---|
| Life lost | 1 HP/s |
| Cooldown | 18 s |
| Range | 8 blocks (line) |
| Lasts | 15 s |
| Spreads within | 2.5 blocks |
| Other diseases wait | 6 s |

## Coughing Fit { #shiku-coughing-fit }

![](../abilities/shiku-coughing-fit.png){ .ability-icon } *Active*

The user gives a coughing fit to the enemy they look at. Now and then one of its abilities fails and has to wait.

It passes to everyone near the sick one but never back to the user. A strong Haki breaks it and cures the sick around.

| Stat | Value |
|---|---|
| Cough chance | 50 % |
| Every | 2 s |
| A coughed ability waits | 5 s |
| Cooldown | 20 s |
| Range | 8 blocks (line) |
| Lasts | 20 s |
| Spreads within | 2.5 blocks |
| Other diseases wait | 6 s |

## Feminization Disease { #shiku-feminization }

![](../abilities/shiku-feminization.png){ .ability-icon } *Active*

The user gives the Feminization Disease to the enemy they look at. A player takes the other build, anyone who catches it is dazed a moment and hits weaker.

It lasts the longest and passes the furthest, to everyone near the sick one but never back to the user. A strong Haki breaks it and cures the sick around.

| Stat | Value |
|---|---|
| Dazed | 3 s |
| Their blows deal | 85 % |
| Cooldown | 45 s |
| Range | 8 blocks (line) |
| Lasts | 120 s |
| Spreads within | 5 blocks |
| Other diseases wait | 6 s |

## Epidemic { #shiku-epidemic }

![](../abilities/shiku-epidemic.png){ .ability-icon } *Active*

The user lays a cloud of the last disease they gave where they look. Everyone who is in it catches the disease for as long as its own ability gives it, but never the user.

| Stat | Value |
|---|---|
| Cooldown | 40 s |
| Hold | 5 s |
| Range | 5 blocks (area) |
