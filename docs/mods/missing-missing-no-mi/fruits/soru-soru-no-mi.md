Found in the base mod's **golden Devil Fruit box**. Eat it and its abilities appear in the ability menu, grouped under the fruit.

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Souls { #soru-souls }

![](../abilities/soru-souls.png){ .ability-icon } *Passive*

Shows the user's own souls and the stolen souls they keep. Abilities that cost a soul take a stolen one first and one of the user's own only when they have no stolen soul left. Each own soul is a share of the user's max health, and the user gets more souls with more Doriki

## Soul Pocus { #soru-soul-pocus }

![](../abilities/soru-soul-pocus.png){ .ability-icon } *Active*

The user asks everyone close to them for their life. Each one that is afraid of the user loses one soul to them, and a creature with only one soul dies

A target is afraid when its health is under half of the user's max health. Conqueror's Haki protects from the fear. The user has to be heard so it fails when they are silenced, and a Logia needs Haki

Everyone has 1 soul for each 1000 Doriki, or for each 20 max health without Doriki, up to 10, and each soul is a share of their max health. Stolen souls are kept and the other abilities use them first, they go back to their owners if the user leaves, dies or loses the power

The user sees pink soul smoke coming out of anyone who is afraid of them

The ability mode key switches between Soul Pocus, the mode it starts in, and Give Back a Soul. Give Back a Soul gives one stolen soul back to the one the user looks at, it only works with a soul the user took from that one

| Stat | Value |
|---|---|
| Cooldown | 1–12 s |
| Range | 6 blocks (area) |
| Give Back Range | 8  blocks |
| Afraid Under | 50 % |
| Stolen Souls Kept | 100 |

## Thundercloud { #soru-thundercloud }

![](../abilities/soru-thundercloud.png){ .ability-icon } *Active*

The user puts a piece of their soul into a storm cloud that comes alive. It guards the user and strikes with lightning by itself whoever hits them or whoever they hit, Indra on one enemy and Tenman Daijizai Tenjin all around it

The user rides the cloud to fly by using it or by jumping twice while it is out. With the sun out too the sun shoots Heavenly Feuer Blitz, and with the sun and the sword out the cloud fires Maser

The cloud holds one soul while it is out, taken from the stolen souls first and from the user's own only when they have no stolen soul left. If it is destroyed the soul comes back after 60 seconds

## Sun { #soru-sun }

![](../abilities/soru-sun.png){ .ability-icon } *Active*

The user puts a piece of their soul into a ball of fire that comes alive. It guards the user and burns by itself whoever hits them or whoever they hit, Heavenly Feuer on one enemy and Heavenly Bonbon that bursts around it

While the sun is out the user's own hits set enemies on fire. With the thundercloud out too the sun shoots Heavenly Feuer Blitz

The sun holds one soul while it is out, taken from the stolen souls first and from the user's own only when they have no stolen soul left. If it is destroyed the soul comes back after 60 seconds

## Soul Sword { #soru-soul-sword }

![](../abilities/soru-soul-sword.png){ .ability-icon } *Active*

The user puts a piece of their soul into a sword that appears in their hand. Using the sword lets it go and it fights by itself, using it on the flying sword takes it back in hand

Every few seconds a hit of the sword is a special hit. Ikoku sends a cut flying forward, with the sun out it is Cognac and burns, with the thundercloud out it is Raitei and calls lightning

The sword holds one soul while it is out, taken from the stolen souls first and from the user's own only when they have no stolen soul left. If it is destroyed the soul comes back after 60 seconds

## Misery { #soru-misery }

![](../abilities/soru-misery.png){ .ability-icon } *Active*

The user fuses the thundercloud, the sun and the sword into Misery, a giant of fire and lightning that runs down their enemies and burns everything around her, for up to 60 seconds. It only works with the three out and costs no soul, the three keep theirs inside her

Using it again splits her and the three come back, as they do when the time is over. Using the ability of one of the three splits her too, that one stays in and the two others come back. If she is destroyed the three are destroyed too and their souls come back after 60 seconds

| Stat | Value |
|---|---|
| Cooldown | 60 s |
| Hold | 60 s |
| Burns Around Her | 12  / s |
| Homie Health | 100 |

## Sacrifice { #soru-sacrifice }

![](../abilities/soru-sacrifice.png){ .ability-icon } *Active*

The user burns one soul to get stronger and bigger for a while. Each use burns one more soul, up to 5

The stolen souls are burnt first and the user's own only when they have no stolen soul left. Burning their own souls lowers their max health until it ends, and the last soul can never be burnt

| Stat | Value |
|---|---|
| Cooldown | 1 s |
| Attack Damage per Soul | +2 |
| Size per Soul | +10 % |
| Souls Burnt at Most | 5 |
| Lasts | 30 s |

## Geburtstag { #soru-geburtstag }

![](../abilities/soru-geburtstag.png){ .ability-icon } *Active*

The user puts a soul into a creation of another devil fruit user, like a biscuit soldier, and it fights for the user from now on

It holds one soul while it stands, taken from the stolen souls first and from the user's own only when they have no stolen soul left. If it is destroyed the soul comes back after 60 seconds

| Stat | Value |
|---|---|
| Cooldown | 10 s |
| Range | 10 blocks (line) |
