Found in the base mod's **iron Devil Fruit box**. Eat it and its abilities appear in the ability menu, grouped under the fruit.

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Vipera Glaive { #vipera-glaive }

![](../abilities/vipera-glaive.png){ .ability-icon } *Active · Punch*

![Vipera Glaive](../objects/vipera-glaive.png){ .form-picture }

The user flattens the sword they hold, press the Alt key to switch between the two

Vipera Glaive makes the blade stretch like a snake to cut the enemy the user is looking at, after which it comes back

Corrida Glaive folds the sword into a bull-headed mace, the next sword hit deals more damage and sends the enemy flying

![](../abilities/death-enjambre.png){ .ability-icon } *Active*

## Steel Cape { #steel-cape }

![](../abilities/steel-cape.png){ .ability-icon } *Active*

![Steel Cape](../objects/steel-cape.png){ .form-picture }

The user needs to wear a cape. Turns the cape into a steel sheet in front of the user, which blocks the attacks from the front and damages the weapon that hit it

## Arma Bandera { #arma-bandera }

![](../abilities/arma-bandera.png){ .ability-icon } *Active · Punch*
