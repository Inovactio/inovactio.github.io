Found in the base mod's **wooden Devil Fruit box**. Eat it and its abilities appear in the ability menu, grouped under the fruit.

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Stinger Finger { #toge-stinger-finger }

![](../abilities/toge-stinger-finger.png){ .ability-icon } *Active*

The user stretches their fingers into long spikes and slashes the enemies in front twice, against a wall the spikes dig a passage through it.

Spikes get stuck in wool, carpets and leather armour and the user can't move for a moment.

With the **Alt key** it is **Double Stinger**: Both hands turn into one big spike each and stab the enemy in front again and again.

| Stat | Stinger Finger | Double Stinger |
|---|---|---|
| Damage type | Fist, Physical | Fist, Physical |
| Haki | Hardening | Hardening |
| Cooldown | 6 s | 10 s |
| Damage | 8 | — |
| Max Targets | 3 | — |
| Reach | 6 blocks | 3 blocks |
| Stabs | — | 5 |
| Total Damage | — | 18 |

## Stinger Hedgehog { #toge-stinger-hedgehog }

![](../abilities/toge-stinger-hedgehog.png){ .ability-icon } *Active · Transformation*

![Stinger Hedgehog](../forms/toge-stinger-hedgehog.png){ .form-picture }

The user rolls up into a ball of spikes like a sea urchin and rolls over the enemies, the ones who hit it by hand get spiked back.

Falling on enemies from up high hurts them a lot more.

## Sewing Stinger { #toge-sewing-stinger }

![](../abilities/toge-sewing-stinger.png){ .ability-icon } *Active*

The user grows short spikes under their feet and runs faster.

With the **Alt key** it is **Sewing Stinger**: a long spike grows under each foot, the user walks up high on them like stilts and tramples the enemies under and next to their feet.
