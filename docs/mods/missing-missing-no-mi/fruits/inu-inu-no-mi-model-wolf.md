Found in the base mod's **iron Devil Fruit box**. Eat it and its abilities appear in the ability menu, grouped under the fruit.

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Wolf Walk Point { #wolf-walk-point }

![](../abilities/wolf-walk-point.png){ .ability-icon } *Active · Transformation*

![Wolf Walk Point](../forms/wolf-walk-point.png){ .form-picture }

Transforms the user into a wolf, which focuses on speed and long jumps.

## Wolf Heavy Point { #wolf-heavy-point }

![](../abilities/wolf-heavy-point.png){ .ability-icon } *Active · Transformation*

![Wolf Heavy Point](../forms/wolf-heavy-point.png){ .form-picture }

Transforms the user into a wolf-man hybrid with claws, which focuses on strength.

## Kamitsuki { #kamitsuki }

![](../abilities/kamitsuki.png){ .ability-icon } *Active*

The user jumps at the target and bites it, making it bleed. The whole wolf bites harder.

| Stat | Value |
|---|---|
| Damage type | Physical |
| Haki | Hardening |
| Cooldown | 6 s |
| Damage | 9 |
| Damage in the Wolf Form | 12 |

## Shippu { #shippu }

![](../abilities/shippu.png){ .ability-icon } *Active*

While in the wolf form, the user runs at full speed knocking down all enemies in their path.

| Stat | Value |
|---|---|
| Damage type | Blunt, Physical |
| Haki | Hardening |
| Cooldown | 8 s |
| Damage | 9 |

## Toboe { #toboe }

![](../abilities/toboe.png){ .ability-icon } *Active*

The user howls, weakening and slowing all nearby enemies. During the night the user also hits harder and runs faster for a while.

| Stat | Value |
|---|---|
| Cooldown | 20 s |
| Range | 12 blocks (area) |
| Attack Damage at Night | +3 |
| Speed at Night | +20 % |
| Hunt at Night | 30 s |

## Kyukaku { #kyukaku }

![](../abilities/kyukaku.png){ .ability-icon } *Active*

| Stat | Value |
|---|---|
| Cooldown | 20 s |
| Range | 32 blocks (area) |

## Yako { #yako }

![](../abilities/yako.png){ .ability-icon } *Passive*

| Attack Damage at Night | +3 |
