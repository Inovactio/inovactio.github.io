# Inu Inu no Mi, Model: Bake-danuki

![](../fruit-icons/inu-inu-no-mi-model-bakedanuki.png){ .mod-icon }

| | |
|---|---|
| **Type** | Mythical Zoan |
| **Box** | ![Golden box](../../../assets/mineminenomi/golden_box.png "Golden box: texture from Mine Mine no Mi"){ .box-icon } Golden |
| **Chance per opening** | golden **2.16%**, iron **0.108%**, wooden **0.005%** ([how it works](index.md#box-odds)) |
| **Abilities** | 10: 10 active, 0 passive |
| **Transformations** | [Bake-danuki Heavy Point](#bake-danuki-heavy-point), [Bake-danuki Walk Point](#bake-danuki-walk-point) |

Found in the base mod's **golden Devil Fruit box**. Eat it and its abilities appear in the ability menu, grouped under the fruit.

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Bake-danuki Heavy Point { #bake-danuki-heavy-point }

![](../abilities/bake-danuki-heavy-point.png){ .ability-icon } *Active · Transformation*

Transforms the user into a bake-danuki hybrid, whose brush tail writes the leaves.

## Bake-danuki Walk Point { #bake-danuki-walk-point }

![](../abilities/bake-danuki-walk-point.png){ .ability-icon } *Active · Transformation*

Transforms the user into a small bake-danuki, very quick, whose brush tail writes the leaves.

## Konoha Henge { #item-leaf }

![](../abilities/item-leaf.png){ .ability-icon } *Active*

While in a bake-danuki form, the user writes the name of an object on a leaf, and the leaf becomes it for a while, a wooden, stone or iron tool or sword, a shield, a bow, arrows, torches, ladders or blocks. It never leaves their inventory and turns back into a leaf, and so does a block they place with it

The ability mode key changes what is written, and "Blocks" copies the block they look at

| Stat | Value |
|---|---|
| Cooldown | 30 s |
| Charge | 1 s |

## Bunshin no Ha { #clone-leaf }

![](../abilities/clone-leaf.png){ .ability-icon } *Active*

While in a bake-danuki form, the user writes the name of someone they have seen on a leaf, and the leaf becomes a loyal clone of them for 30 seconds, with half their health and strength and two of their abilities

Whoever the user looks at is remembered. The ability mode key opens the memory, where the one to copy is chosen

| Stat | Value |
|---|---|
| Cooldown | 60 s |
| Charge | 1 s |

## Utsushi no Ha { #attack-leaf }

![](../abilities/attack-leaf.png){ .ability-icon } *Active*

While in a bake-danuki form, the user writes on a leaf the last ability they saw or took in the last 30 seconds, and the leaf becomes it for one use, at 70% of its strength. It stands in this slot until used, then the leaf comes back

| Stat | Value |
|---|---|
| Cooldown | 40 s |
| Charge | 1 s |

## Bake no Ha { #bake-disguise }

![](../abilities/bake-disguise.png){ .ability-icon } *Active*

While in a bake-danuki form, the user puts a leaf on their head and takes the look of a creature or player they have seen, for 60 seconds. The look falls when they hit or are hit. Taking a look ends the form

Whoever the user looks at is remembered. The ability mode key opens the memory, where the look is chosen

| Stat | Value |
|---|---|
| Cooldown | 45 s |
| Hold | 60 s |

## Yami no Ha { #darkness-leaf }

![](../abilities/darkness-leaf.png){ .ability-icon } *Active*

While in a bake-danuki form, the user throws a leaf where they look, which becomes a place of pitch darkness for 10 seconds. Their foes inside are blinded

| Stat | Value |
|---|---|
| Cooldown | 35 s |
| Charge | 1 s |
| Hold | 10 s |
| Range | 6 blocks (area) |

## Henge { #henge }

![](../abilities/henge.png){ .ability-icon } *Active*

While in a bake-danuki form, the user turns into an object. As an umbrella they float down slowly for 10 seconds and turn aside the shots coming at them from the front. As a giant brush they rush ahead, striking every foe on the stroke and leaving a trail of ink

The ability mode key switches between the umbrella and the brush

| Stat | Value |
|---|---|
| Haki | Special |
| Cooldown | 25 s |
| Hold | 10 s |
| Damage | 20 |
| Range | 8–1.5 blocks (line) |

![](../abilities/medicine-leaf.png){ .ability-icon } *Active*

While in a bake-danuki form, the user writes "medicine" on a leaf, which heals 8 health over 4 seconds to the ally they look at, or to themselves

| Stat | Value |
