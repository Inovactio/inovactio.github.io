Found in the base mod's **golden Devil Fruit box**. Eat it and its abilities appear in the ability menu, grouped under the fruit.

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Logia Invulnerability Mori { #logia-invulnerability-mori }

![](../abilities/logia-invulnerability-mori.png){ .ability-icon } *Passive*

Allows the user to avoid attacks by instinctively transforming parts of their body into their specific element

The user's body is made of living wood, fire always hurts them and deals 50% more damage.

## Kogosei { #kogosei }

![](../abilities/kogosei.png){ .ability-icon } *Passive*

During the day and under the sky, the user does not get hungry and slowly regenerates health. Does not work during rain, night or under a roof

| Stat | Value |
|---|---|
| Healing Every 5 s | 1 |

## Hosaku { #ryokuka }

![](../abilities/ryokuka.png){ .ability-icon } *Active*

Every plant around the user grows as with bone meal, crops, saplings and flowers, and the dirt turns into grass. Nothing grows in a claim the user can't build in

| Stat | Value |
|---|---|
| Cooldown | 10 s |
| Range | 6 blocks (area) |

## Jukon { #jukon }

![](../abilities/jukon.png){ .ability-icon } *Active*

![Jukon](../objects/jukon.png){ .form-picture }

Roots come out of the ground where the user is looking and grab up to 6 enemies. They are stuck in place but can still attack.

Use the ability again for Kyusui: the roots drain the enemies every second, healing the user and weakening them

The mode key switches between Jukon, the mode it starts in, and Jukai. Jukai sends a wave of roots forward through the ground, it hits every enemy on its way and tangles them for a moment

| Stat | Jukon | Jukai |
|---|---|---|
| Damage type | Blunt, Indirect | Blunt, Indirect |
| Haki | Special | Special |
| Cooldown | 14 s | 15 s |
| Duration | 5.45 s |  |
| Damage | 24 | 32 |
| Range | 5 blocks (area) |  |
| Max Targets | 6 |  |
| Kyusui Drain per Second | 5 |  |
| Wave Length |  | 18 blocks |
| Tangled |  | 2 s |

## Edayari { #edayari }

![](../abilities/edayari.png){ .ability-icon } *Active*

![Edayari](../forms/edayari.png){ .form-picture }

The user's fingers extend into long branches that spread out in a fan and pierce every enemy on them. They are stuck in place but can still attack

Use the ability again for Kyusui: the branches drain the enemies every second, healing the user and weakening them.

The mode key switches between Edayari, the mode it starts in, and Eda Shigure. Eda Shigure thrusts the branch again and again where the user looks, hitting every enemy on the line each time

| Stat | Edayari | Eda Shigure |
|---|---|---|
| Damage type | Physical | Physical |
| Haki | Hardening | Hardening |
| Cooldown | 8 s | 16 s |
| Duration | 3 s |  |
| Damage | 28 |  |
| Branches | 5 |  |
| Thrusts |  | 8 |
| Total Damage |  | 40 |
| Range | 12 blocks (line) | 12 blocks (line) |

![](../abilities/senbon-kui.png){ .ability-icon } *Active*

Sharp wooden stakes burst out of the user's whole body, hitting every enemy around, making them bleed and throwing them back

| Stat | Value |

| Cooldown | 12 s |

## Konwan { #konwan }

![](../abilities/konwan.png){ .ability-icon } *Active*

![Konwan](../forms/konwan.png){ .form-picture }

Two arms of sharp roots grow out of the user's back. While active, each of their own hits in close combat is followed by a hit of a root arm that makes the enemy bleed

| Stat | Value |
|---|---|
| Damage type | Physical |
| Haki | Hardening |
| Cooldown | 20 s |
| Duration | 30 s |
| Root Arm Blow | 8 |
| Bleeding | 3 s |

## Jurin Heki { #jurin-heki }

![](../abilities/jurin-heki.png){ .ability-icon } *Active*

![Jurin Heki](../objects/jurin-heki.png){ .form-picture }

A wall of trees rises out of the ground in front of the user. It stops enemies and projectiles and takes hits until it breaks. Fire burns it unless Bokarin is active. Using the ability again brings the wall down. As a golem, the wall is twice as big and its wood harder

| Stat | Value |
|---|---|
| Cooldown | 20 s |
| Duration | 15 s |
| Wall Health | 150 |

## Kinniku Mori Mori { #kinniku-mori-mori }

![](../abilities/kinniku-mori-mori.png){ .ability-icon } *Active · Transformation*

![Kinniku Mori Mori](../forms/kinniku-mori-mori.png){ .form-picture }

While standing on natural ground, the user transforms into a tree golem, increasing the damage and the range of their punches and their armor but making them slower. The other abilities are also stronger and bigger while in this form.

The size can be changed before using it, the giant golem lasts less and has a longer cooldown

| Stat | Kinniku Mori Mori | Giant Kinniku Mori Mori |
|---|---|---|
| Cooldown | 6–30 s | 18–90 s |
| Charge | 1 s | 1 s |
| Hold | 60 s | 30 s |
| Size | x3 | x8 |
| Fist Damage | +14 | +30 |
| Armor | +8 | +14 |

## Wakagi { #wakagi }

![](../abilities/wakagi.png){ .ability-icon } *Passive*

![Wakagi](../forms/wakagi.png){ .form-picture }

If the user would die while in the golem form, the golem falls instead and the user grows back from a sapling a few blocks away with a part of their health. Does not work if killed by a very strong fire attack.

| Stat | Value |
|---|---|
| Cooldown | 300 s |
| Health Kept | 30 % |
| As a Sapling | 3 s |

## Bokarin { #bokarin }

![](../abilities/bokarin.png){ .ability-icon } *Active*

The user fills their wood with water so fire doesn't deal extra damage to them anymore, except for very strong fire attacks. The user moves and attacks slower while active

| Stat | Value |
|---|---|
| Cooldown | 5 s |
| Fire That Burns Through | 20 |

**Stats while active**

| Stat | Value |
|---|---|
| Speed | <span class="stat-malus">x0.8</span> |
| Attack Speed | <span class="stat-malus">x0.8</span> |

## Hanaguruma { #hanaguruma }

![](../abilities/hanaguruma.png){ .ability-icon } *Active*

![Hanaguruma](../forms/hanaguruma.png){ .form-picture }

A giant flower grows on the user's back and spins like a propeller allowing them to fly. Fire burns the flower and stops the flight. Can't be used in the golem form.

## Hisho { #hisho }

![](../abilities/hisho.png){ .ability-icon } *Passive*

While the flower is spinning the user can fly, until they have no more stamina
