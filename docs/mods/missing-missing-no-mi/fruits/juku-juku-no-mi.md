Found in the base mod's **wooden Devil Fruit box**. Eat it and its abilities appear in the ability menu, grouped under the fruit.

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Decaying Touch { #decaying-touch }

![](../abilities/decaying-touch.png){ .ability-icon } *Active*

The block the user touches rots, and the rot spreads to the blocks around it. A rotten block crumbles for good, the harder it is the longer it takes.

| Stat | Value |
|---|---|
| Cooldown | 6 s |
| Range | 5 blocks (line) |
| Range | 4 blocks (area) |

## Sinkhole { #sinkhole }

![](../abilities/sinkhole.png){ .ability-icon } *Active*

The ground the user looks at rots into a pit that goes on deepening for a while. Sneaking, or with no ground in sight, the pit opens under the user's own feet.

| Stat | Value |
|---|---|
| Cooldown | 15 s |
| Range | 8 blocks (line) |
| Range | 4.6 blocks (area) |
| Depth | 6 blocks |

## Kare-San-Sui { #kare-san-sui }

![](../abilities/kare-san-sui.png){ .ability-icon } *Active*

The ceiling above the enemy the user looks at rots through and falls on whoever is under it. The fallen blocks break where they land.

The harder the ceiling, the longer it takes to rot and the more it hurts. A giant's rubble hits twice as hard

| Stat | Value |
|---|---|
| Cooldown | 20 s |
| Range | 16 blocks (line) |
| Damage a Block, by Hardness | 2–40 |

## Aging Touch { #aging-touch }

![](../abilities/aging-touch.png){ .ability-icon } *Active*

Applies ![](../effect-icons/aged.png){ .effect-mini }[Aged](../effects.md#effect-aged)

The enemy the user touches grows old. A creature stays old until it dies, a player or a boss for a while. A young animal grows up instead.

![](../abilities/rot-gear.png){ .effect-mini }With the **Alt key** it is **Rot Gear**: the weapon and the armor of the enemy the user touches rot, and a piece that had too little durability left breaks.

| Stat | Aging Touch | Rot Gear |
|---|---|---|
| Cooldown | 15 s | 15 s |
| Range | 4.5 blocks (line) | 4.5 blocks (line) |
| Speed of the Aged | <span class="stat-malus">-33 %</span> | |
| Damage of the Aged | <span class="stat-malus">-40 %</span> | |
| Old Age on Players | 90 s | |
| Durability Lost | | <span class="stat-malus">-34 %</span> |

## Ripen { #ripen }

![](../abilities/ripen.png){ .ability-icon } *Active*

The crops, the saplings and the young animals around the user reach full growth at once.

| Stat | Value |
|---|---|
| Cooldown | 30 s |
| Range | 6 blocks (area) |
