# Tori Tori no Mi, Model: Falcon

![](../fruit-icons/tori-tori-no-mi-model-falcon.png){ .mod-icon }

| | |
|---|---|
| **Type** | Zoan |
| **Box** | ![Iron box](../../../assets/mineminenomi/iron_box.png "Iron box: texture from Mine Mine no Mi"){ .box-icon } Iron |
| **Chance per opening** | iron **2.45%**, wooden **0.122%** ([how it works](index.md#box-odds)) |
| **Abilities** | 7: 5 active, 2 passive |
| **Transformations** | [Falcon Assault Point](#falcon-assault-point), [Falcon Fly Point](#falcon-fly-point) |

Found in the base mod's **iron Devil Fruit box**. Eat it and its abilities appear in the ability menu, grouped under the fruit.

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Falcon Assault Point { #falcon-assault-point }

![](../abilities/falcon-assault-point.png){ .ability-icon } *Active · Transformation*

Transforms the user into a falcon hybrid that can fly and still holds its weapons.

## Falcon Fly Point { #falcon-fly-point }

![](../abilities/falcon-fly-point.png){ .ability-icon } *Active · Transformation*

Transforms the user into a great falcon that flies fast and can carry a rider.

## Falcon Flight { #falcon-flight }

*Passive*

Requires Falcon Assault Point or Falcon Fly Point to be active.

## Falcon Rideable { #falcon-rideable }

![](../abilities/falcon-rideable.png){ .ability-icon } *Passive*

Allows another player to ride on the falcon's back.

Requires Falcon Fly Point to be active.

## Tobizume { #tobizume }

![](../abilities/tobizume.png){ .ability-icon } *Active*

From the air, dives on the target and slashes it with the talons.

| Stat | Value |
|---|---|
| Damage type | Slash, Physical |
| Haki | Hardening |
| Cooldown | 8 s |
| Damage | 9 |

## Tsukami Otoshi { #tsukami-otoshi }

![](../abilities/tsukami-otoshi.png){ .ability-icon } *Active*

In the falcon form, seizes the enemy below in the talons and carries it off. Press again to drop it.

| Stat | Value |
|---|---|
| Cooldown | 12 s |
| Hold | 6 s |

## Hane Arashi { #hane-arashi }

![](../abilities/hane-arashi.png){ .ability-icon } *Active*

Beats the wings: enemies in front are thrown back, and projectiles are blown back the way they came.

| Stat | Value |
|---|---|
| Damage type | Indirect |
| Element | Wind |
| Cooldown | 10 s |
| Range | 7 blocks (area) |
| Damage | 3 |
