# Advancements

Impel Down has an advancement tab of its own, **Impel Down**: a thread down the tower, level by level. **None gives a reward.**

| Advancement | How to get it |
|---|---|
| **Impel Down** | Go in through a prison's door. |
| **Chief Of The Guard** (goal) | Kill the chief of the guard. |
| **Jailbreak** | Free a prisoner. |
| **Level 1 Crimson Hell** | Get down to level 1. |
| **Not In My Cell** | Kill a venomous spider. |
| **Blue Brute** | Kill a Blugori. |
| **Head Jailer** (goal) | Kill a head jailer. |
| **Level 2 Wild Beast Hell** | Get down to level 2. |
| **Snake Or Chicken** (goal) | Kill a Basilisk. |
| **Stop Repeating** | Kill a Manticore. |
| **No More Noodles** (goal) | Kill the Sphinx. |
| **Level 3 Starvation Hell** | Get down to level 3. |
| **Level 4 Blazing Hell** | Get down to level 4. |
| **Level 5 Freezing Hell** | Get down to level 5. |
| **Wolf Unit** | Kill a white wolf. |
| **Level 6 Eternal Hell** | Get down to level 6. |
| **Warden** (goal) | Kill the warden. |
| **Rock Bottom** (challenge) | Kill the warden on level 6. |
