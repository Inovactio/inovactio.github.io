Found in the base mod's **iron Devil Fruit box**. Eat it and its abilities appear in the ability menu, grouped under the fruit.

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Hone Hone Point { #hone-hone-point }

![](../abilities/hone-hone-point.png){ .ability-icon } *Active · Transformation*

The user wears their skeleton on the outside, which makes the other bone techniques stronger while active

## Bone Throw { #bone-throw }

![](../abilities/bone-throw.png){ .ability-icon } *Active*

Throws a bone that comes back to the user, hitting enemies both ways.

| Stat | Value |
|---|---|
| Cooldown | 7 s |
| Projectile damage | 6 |

## Bone Blade { #bone-blade }

![](../abilities/bone-blade.png){ .ability-icon } *Active*

Grows a long bone blade out of the user's arm that can be used as a sword.

## Bone Shards { #bone-shards }

![](../abilities/bone-shards.png){ .ability-icon } *Active*

| Stat | Value |
|---|---|
| Cooldown | 5 s |
| Projectile damage | 2 |

## Bone Mend { #bone-mend }

![](../abilities/bone-mend.png){ .ability-icon } *Active*

| Stat | Value |

| Cooldown | 20 s |
