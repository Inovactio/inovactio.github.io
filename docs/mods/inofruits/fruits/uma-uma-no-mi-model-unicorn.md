Found in the base mod's **golden Devil Fruit box**. Eat it and its abilities appear in the ability menu, grouped under the fruit.

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Uma Uma Walk Point { #uma-uma-walk-point }

![](../abilities/uma-uma-walk-point.png){ .ability-icon } *Active · Transformation*

![Uma Uma Walk Point](../forms/uma-uma-walk-point.png){ .form-picture }

Transforms the user into a unicorn, which focuses on speed and can carry allies.

## Uma Uma Heavy Point { #uma-uma-heavy-point }

![](../abilities/uma-uma-heavy-point.png){ .ability-icon } *Active · Transformation*

![Uma Uma Heavy Point](../forms/uma-uma-heavy-point.png){ .form-picture }

Transforms the user into a unicorn hybrid, which focuses on strength and the horn.

## Horn Thrust { #horn-thrust }

![](../abilities/horn-thrust.png){ .ability-icon } *Active*

Stabs the target with the horn, ignoring armor, absorption and Logia intangibility. In the Heavy Point it also lifts the target.

| Stat | Value |
|---|---|
| Damage type | Physical, Slash |
| Element | Light |
| Haki | Hardening |
| Cooldown | 8 s |
| Damage | 24 |
| Pierces | Armour, Logia |

## Alicorn { #alicorn }

![](../abilities/alicorn.png){ .ability-icon } *Passive*

The light of the horn removes every harmful effect on the user except stuns and heals the user while transformed. Both use light, which comes back over time and with every horn hit.

## Unicorn Rideable { #unicorn-rideable }

![](../abilities/unicorn-rideable.png){ .ability-icon } *Passive*

Allows other players to ride on the unicorn's back.

## Unicorn Flight { #unicorn-flight }

![](../abilities/unicorn-flight.png){ .ability-icon } *Passive*

Allows the user to fly while transformed, leaving a rainbow behind them

Requires Uma Uma Walk Point or Uma Uma Heavy Point to be active.
