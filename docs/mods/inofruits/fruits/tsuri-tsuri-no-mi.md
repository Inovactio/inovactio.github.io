# Tsuri Tsuri no Mi

**Paramecia** · Wooden box · 4 abilities

Found in the base mod's **wooden Devil Fruit box**. Eat it and its abilities appear in the ability menu, grouped under the fruit.

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Ipponzuri { #ipponzuri }

![](../abilities/ipponzuri.png){ .ability-icon } *Active*

Casts a fishing line at whatever the user is looking at and reels it in.

| Stat | Value |
|---|---|
| Cooldown | 8 s |
| Damage | 4 |
| Range | 50 blocks (line) |

## Tsuriage { #tsuriage }

![](../abilities/tsuriage.png){ .ability-icon } *Active*

Throws a bunch of lines at the ground, bringing back every dropped item within 26 blocks.

| Stat | Value |
|---|---|
| Cooldown | 5 s |
| Range | 26 blocks (area) |

## Kaginawa { #kaginawa }

![](../abilities/kaginawa.png){ .ability-icon } *Active*

Hooks onto anything in sight up to 50 blocks away and pulls the user to it.

| Stat | Value |
|---|---|
| Cooldown | 5 s |
| Damage | 5 |
| Range | 50 blocks (line) |

## Tsuribito { #tsuribito }

![](../abilities/tsuribito.png){ .ability-icon } *Passive*

Anything the user fishes up comes up twice

The fishing rod also never loses durability.
