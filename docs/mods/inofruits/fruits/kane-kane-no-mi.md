# Kane Kane no Mi

![](../fruit-icons/kane-kane-no-mi.png){ .mod-icon }

| | |
|---|---|
| **Type** | Paramecia |
| **Theme** | Treasure |
| **Box** | ![Wooden box](../../../assets/mineminenomi/wooden_box.png "Wooden box: texture from Mine Mine no Mi"){ .box-icon } Wooden |
| **Chance per opening** | wooden **2.32%** ([how it works](index.md#box-odds)) |
| **Abilities** | 6: 5 active, 1 passive |

Found in the base mod's **wooden Devil Fruit box**. Eat it and its abilities appear in the ability menu, grouped under the fruit.

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Komyaku { #komyaku }

![](../abilities/komyaku.png){ .ability-icon } *Active*

Highlights everything valuable within 32 blocks for 12 seconds, even through walls.

| Stat | Value |
|---|---|
| Cooldown | 15 s |
| Range | 32 blocks (area) |

## Meate { #meate }

![](../abilities/meate.png){ .ability-icon } *Active*

|---|---|

| Range | 64 blocks (area) |

## Kiun { #kiun }

![](../abilities/kiun.png){ .ability-icon } *Passive*

**Stats while active**

|---|---|

## Zeni Nage { #zeni-nage }

![](../abilities/zeni-nage.png){ .ability-icon } *Active*

Flicks a coin hardened into gold at the target, for 1 berry a throw. The luckier the user, the harder it hits.

| Stat | Value |
|---|---|
| Cooldown | 2 s |
| Damage | 6–10 |
| Range | 24 blocks (line) |

## Oatari { #oatari }

![](../abilities/oatari.png){ .ability-icon } *Active*

| Stat | Value |
|---|---|
