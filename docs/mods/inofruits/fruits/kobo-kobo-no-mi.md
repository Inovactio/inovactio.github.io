# Kobo Kobo no Mi

![](../fruit-icons/kobo-kobo-no-mi.png){ .mod-icon }

**Paramecia** · ![Wooden box](../../../assets/mineminenomi/wooden_box.png "Wooden box: texture from Mine Mine no Mi"){ .box-icon } Wooden box · 4 abilities

Found in the base mod's **wooden Devil Fruit box**. Eat it and its abilities appear in the ability menu, grouped under the fruit.

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Te Kobo { #te-kobo }

![](../abilities/te-kobo.png){ .ability-icon } *Active*

Forces the first target in the way to let go of whatever they're holding for 3 seconds

| Stat | Value |
|---|---|
| Cooldown | 10 s |
| Range | 8 blocks (line) |

## Hako Kobo { #hako-kobo }

![](../abilities/hako-kobo.png){ .ability-icon } *Active*

Every chest, furnace, hopper and Minecart with Chest nearby spills its items on the floor.

| Stat | Value |
|---|---|
| Cooldown | 20 s |
| Range | 8 blocks (area) |

## Chi Kobo { #chi-kobo }

![](../abilities/chi-kobo.png){ .ability-icon } *Active*

|---|---|

## Hara Kobo { #hara-kobo }

![](../abilities/hara-kobo.png){ .ability-icon } *Active*

| Stat | Value |
|---|---|
| Cooldown | 5 s |
