# Wata Wata no Mi

**Paramecia** · Wooden box · 5 abilities

Found in the base mod's **wooden Devil Fruit box**. Eat it and its abilities appear in the ability menu, grouped under the fruit.

!!! note "About the values"
    The values are those of the ability's tooltip in game, with the base mod's default settings. Damage is shown on the base mod's scale, as in the ability screen.

## Wata Yoroi { #wata-yoroi }

![](../abilities/wata-yoroi.png){ .ability-icon } *Active · Transformation*

Covers the chest, shoulders and arms in cotton, reducing damage from hits and falls.

## Watagumo { #watagumo }

![](../abilities/watagumo.png){ .ability-icon } *Active*

Creates a cloud of cotton that blinds anyone inside and hides the user

| Stat | Value |
|---|---|
| Hold | 8 s |
| Cooldown | 15 s |

## Wataho { #wataho }

![](../abilities/wataho.png){ .ability-icon } *Active*

Throws a packed ball of cotton that picks up whatever it hits and carries it.

| Stat | Value |
|---|---|
| Cooldown | 5 s |
| Projectile damage | 4 |

## Watazumi { #watazumi }

![](../abilities/watazumi.png){ .ability-icon } *Active*

Pulls some cotton off the user and turns it into white wool.

With the armor on there is more cotton, giving three wool instead of one

| Stat | Value |
|---|---|
| Cooldown | 2 s |

## Flammable { #flammable }

*Passive*

!!! info "Hidden ability"
    It does not appear in the ability menu: it works with [Wata Yoroi](#wata-yoroi).

While wearing the cotton armor, the user takes more damage from fire.
