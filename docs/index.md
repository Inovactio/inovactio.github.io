# Inovactio's Minecraft Mods

Player wikis and developer documentation for Inovactio's Minecraft mods. All of them are addons for [Mine Mine no Mi](https://www.curseforge.com/minecraft/mc-mods/mine-mine-no-mi-mod), on **Minecraft 1.20.1** with **Forge**.

<div class="grid cards" markdown>

-   ![](assets/icons/awaken-awaken-no-mi.png){ .card-icon } **Awaken Awaken no Mi**

    ---

    Awakened abilities and forms for 70 of the base mod's Devil Fruits.

    **Needs:** Mine Mine no Mi, AkumaLib

    [:octicons-arrow-right-24: Read the wiki](mods/awaken-awaken-no-mi/index.md)

-   ![](assets/icons/awaken-path.png){ .card-icon } **Awaken Path**

    ---

    A survival progression that awakens a player's Devil Fruit through Doriki and time.

    **Needs:** Mine Mine no Mi

    [:octicons-arrow-right-24: Read the wiki](mods/awaken-path/index.md)

-   ![](assets/icons/inofruits.png){ .card-icon } **InoFruits**

    ---

    34 brand-new Devil Fruits the base mod does not have, found in its own Devil Fruit boxes.

    **Needs:** Mine Mine no Mi, AkumaLib

    [:octicons-arrow-right-24: Read the wiki](mods/inofruits/index.md)

-   ![](assets/icons/sky-island.png){ .card-icon } **Sky Island**

    ---

    Skypiea as a dimension of its own, reached by a Knock-Up Stream: the cloud sea, the Angel Islands, the Upper Yards and Shandora.

    **Needs:** Mine Mine no Mi, AkumaLib

    [:octicons-arrow-right-24: Read the wiki](mods/sky-island/index.md)

-   ![](assets/icons/akumalib.png){ .card-icon } **AkumaLib**

    ---

    The shared ability framework the addons are built on. A library for mod developers: it adds nothing a player can see.

    **Needs:** Mine Mine no Mi

    [:octicons-arrow-right-24: Developer docs](akumalib/index.md)

</div>
