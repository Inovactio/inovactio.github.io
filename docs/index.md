# Inovactio's Mine Mine no Mi addons

Player wikis and developer documentation for the addons Inovactio makes for [Mine Mine no Mi](https://www.curseforge.com/minecraft/mc-mods/mine-mine-no-mi-mod), on **Minecraft 1.20.1** with **Forge**.

<div class="grid cards" markdown>

-   :material-fire:{ .lg .middle } **Awaken Awaken no Mi**

    ---

    Awakened abilities and forms for 70 of the base mod's Devil Fruits.

    **Needs:** Mine Mine no Mi, AkumaLib

    [:octicons-arrow-right-24: Read the wiki](mods/awaken-awaken-no-mi/index.md)

-   :material-trending-up:{ .lg .middle } **Awaken Path**

    ---

    A survival progression that awakens a player's Devil Fruit through Doriki and time.

    **Needs:** Mine Mine no Mi

    [:octicons-arrow-right-24: Read the wiki](mods/awaken-path/index.md)

-   :material-fruit-cherries:{ .lg .middle } **InoFruits**

    ---

    28 brand-new Devil Fruits the base mod does not have, found in its own Devil Fruit boxes.

    **Needs:** Mine Mine no Mi, AkumaLib

    [:octicons-arrow-right-24: Read the wiki](mods/inofruits/index.md)

-   :material-ferry:{ .lg .middle } **Cruise Cruise no Mi**

    ---

    A work system for Mine Mine no Mi.

    **Not released yet.**

    [:octicons-arrow-right-24: Status](mods/cruise/index.md)

-   :material-weather-cloudy:{ .lg .middle } **Sky Island**

    ---

    Sky island dimensions.

    **Not released yet.**

    [:octicons-arrow-right-24: Status](mods/sky-island/index.md)

-   :material-code-braces:{ .lg .middle } **AkumaLib**

    ---

    The shared ability framework the addons are built on. A library for mod developers: it adds nothing a player can see.

    **Needs:** Mine Mine no Mi

    [:octicons-arrow-right-24: Developer docs](akumalib/index.md)

</div>
