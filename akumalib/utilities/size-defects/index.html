    Size defects register¶

    Every kind of size defect found so far, in game or in review, with its cause, the shared fix and where it was applied. Read it before touching an ability for the size system (#482), in AkumaLib or in an addon: when an ability shows one of these symptoms, use the shared fix named here instead of writing a new one.

    The rules behind every row:

    • Giants are SIZE 4 (attribute akumalib:size, about 7.2 blocks). Test at SIZE 1, 0.5, 2 and 4; 6.667 and 10 only on top, for caps.
    • Nothing changes at SIZE 1 unless the maintainer asked for it. Every fix proves it: census off/on identical, GameTests at SIZE 1 unchanged, a client check at SIZE 1, no added cost.
    • One fix, in shared code. As soon as a defect touches two abilities, the fix goes into a helper: AkumaLib when an addon can meet it too, the addon's util/ otherwise. A fix written inside one ability is for a truly unique case.
    • Which factor. A construct, a projectile or a reach takes the reach factor (√SIZE, x3 at most, AkumaSize.factor(user, Family.REACH)). A living summon and a shape that shuts its user in take the body (x SIZE, 48 blocks at most).

    Adding a row¶

    When a new size defect is found, add a row in the same change as its fix: the symptom as a player sees it, the cause in one line, the shared fix and the PR. Then look for the same symptom in the other abilities (Missing, InoFruits, Awaken, Awaken Path, Race Race no Mi) and list them on the #897 kit map or on the addon's size ticket.
