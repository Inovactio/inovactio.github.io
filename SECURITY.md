# Security

This repository holds the source of <https://inovactio.github.io/>, a static documentation site.

If you find a security problem (in the site, its build workflow, or content that should not be public),
please report it privately through **[Report a vulnerability](https://github.com/Inovactio/inovactio.github.io/security/advisories/new)**
rather than in a public issue.
